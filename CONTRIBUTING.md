# Contributing

Thank you for wanting to make the 23artifacts plugin better.

This repository is generated from the 23artifacts source and published automatically each time the plugin changes, so a pull request here can't be merged: the next release would overwrite it. To suggest a change — a fix to a guide, a clearer command, something the README gets wrong — [open an issue](https://github.com/23made/23artifacts-plugin/issues/new/choose) and describe it; the change is made at the source and arrives here with the next release.

The skill's guides (`skills/publish-artifact/`) are the same ones the 23artifacts connector serves to every assistant, so a change to one reaches everyone who uses 23artifacts, with or without the plugin.

Questions about your account or billing go to [23artifacts.com/support](https://23artifacts.com/support). Report a security problem privately to security@23artifacts.com, never in an issue.
